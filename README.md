Четыре основные лабораторные работы по заданию Р. В. Душкина из PDF в корне проекта. Реализация на Python; ключевые эволюционные операторы написаны самостоятельно.

Полная повторная проверка от 8 ноября 2026 года и перечень исправлений: [AUDIT.md](AUDIT.md).

Индивидуальные параметры: N = 11, группа 517, Q = 1, Y = 26.

`V = 1 + ((17 × 11 + 7 × 1 + 26) mod 20) = 1`.

| Директория | Задача | Основное сравнение | Запусков на метод |
|---|---|---|---:|
| Lab1 | Функция сферы, 6 измерений | Два масштаба мутации ГА; случайный поиск | 20 |
| Lab2 | Рюкзак: масса и объём, 40 предметов | Ремонт и штраф; два кроссовера; случайный поиск | 20 |

## Установка

Проверено на Windows, Python 3.13.14. Команды выполняются из корня проекта в PowerShell. Активация окружения не требуется.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Полное воспроизведение

```powershell
.\.venv\Scripts\python.exe reproduce.py
```

Команда последовательно запускает тесты, полные экспериментальные серии, сборку четырёх PDF и независимую сверку сохранённых результатов. CSV, графики и отчёты перезаписываются результатами нового измерения. Итоговый протокол с контрольными суммами файлов сохраняется в `verification.json`. Стохастические результаты воспроизводятся при тех же seed и версиях библиотек; время выполнения зависит от компьютера и нагрузки.

Для рендеринга всех страниц отчётов:

```powershell
.\.venv\Scripts\python.exe reproduce.py --reports-only --render
```

Изображения проверки сохраняются в `tools/_qa/`. PDF используют A4, поля 2 см, встроенный Times New Roman с кириллицей. На другой ОС пути к шрифтам задаются через `tools/build_reports.py --font-dir`; численные эксперименты не зависят от Windows.

## Отдельные команды

```powershell
.\.venv\Scripts\python.exe Lab1\run.py
.\.venv\Scripts\python.exe Lab2\main.py
.\.venv\Scripts\python.exe Lab3\main.py
.\.venv\Scripts\python.exe Lab4\experiment.py
.\.venv\Scripts\python.exe -m pytest Lab1 Lab2 Lab3 Lab4 tools -q
.\.venv\Scripts\python.exe tools\build_reports.py --render
.\.venv\Scripts\python.exe tools\verify_results.py --output verification.json
```

Каждая лабораторная содержит исходники, конфигурацию, инструкцию `README.md`, отчёт `report.md` и `report.pdf`, таблицы отдельных запусков и статистики, графики и блок-схему. В работах № 2–4 приложены входные данные. Подробные параметры CLI и перечни результатов приведены в соответствующих README.

В сравнениях фиксируется число фактических оценок целевой функции; оценки локального поиска включены в бюджет. Точный динамический метод в № 2 и полный перебор в № 3 служат независимыми эталонами, а не эволюционными оптимизаторами. В № 4 приведены конструктивный ориентир и нижняя граница, без заявления о доказанной оптимальности маршрута. Сценарий демонстрации проекта на 6 минут - `Lab4/DEMO.md`.
