# Заявка на проект лабораторной работы № 4

Тема 1 из перечня задания: меметический алгоритм маршрутизации.

Заявка подготовлена до основной реализации.

Постановка: найти короткий замкнутый маршрут посещения 40 пунктов на плоскости. Расстояние евклидово; каждый пункт посещается ровно один раз. Предметная интерпретация - объезд пунктов обслуживания без ограничений вместимости и временных окон.

Представление: перестановка индексов пунктов. Целевая функция - сумма длин рёбер замкнутого маршрута. Специализированные операторы: упорядоченный кроссовер OX и инверсия фрагмента.

Сравниваемые методы: базовый генетический алгоритм и его меметический вариант с локальным поиском 2-opt. Локальный поиск применяется к части потомков; проверка каждого соседнего маршрута включается в общий бюджет оценок. Сохраняется лучший найденный маршрут.

Данные: синтетический экземпляр из четырёх пространственных кластеров, 40 пунктов, seed данных 20261104. Координаты сохраняются в CSV. Сравнение проводится на одном экземпляре при одинаковом бюджете 18000 оценок, по 30 независимых запусков каждого метода.

Критерии: длина лучшего маршрута; среднее, медиана, стандартное отклонение, минимум и максимум по запускам; динамика по числу оценок; время работы. Дополнительные ориентиры - ближайший сосед и нижняя граница по минимальному остовному дереву.

Риски: локальный поиск может расходовать бюджет без увеличения разнообразия; преждевременная сходимость; отсутствие доказательства глобальной оптимальности. План проверки: корректность перестановок, замыкания маршрута, оператора 2-opt, счётчика оценок и повторяемости по seed.
