# Лабораторная работа № 4

Вариант 1: меметический алгоритм для замкнутой евклидовой маршрутизации. Сравниваются базовый ГА и две частоты локального поиска (0,2 и 0,005), по 30 запусков каждой конфигурации. Собственные реализации ГА, OX, инверсии, 2-opt и минимального остовного дерева. Ключевые операторы находятся в `algorithm.py`.

Установка из корня проекта (Python 3.13; версии зависимостей зафиксированы в корневом requirements.txt):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Полное повторение эксперимента из корня:

```powershell
.\.venv\Scripts\python.exe Lab4\experiment.py
```

Из директории Lab4:

```powershell
..\.venv\Scripts\python.exe experiment.py --runs 30 --budget 18000 --seed-start 4000
..\.venv\Scripts\python.exe -m pytest -q
```

Параметры находятся в `config.json`. Данные зафиксированы в `data.csv`. Если файл данных отсутствует, он воспроизводится по seed из конфигурации. Для иных данных используется `--data path/to/coordinates.csv`; колонки должны быть `city,x,y`, идентификаторы - последовательные целые числа от 0 в порядке строк, число строк - равным `cities` в конфигурации. Генератор поддерживает любое целое число пунктов от 4, распределяя остаток между четырьмя кластерами. В фактической конфигурации сохраняются путь и SHA-256 входной таблицы; происхождение данных в отчёте сверяется с генератором.

Результаты: `results/runs.csv`, `summary.csv`, `summary.json`, `traces.csv`, `best_route.csv`, `best_solution.json`, `best_by_method.json`, графики PNG. Три пробных запуска частоты локального поиска сохранены в `results/pilot.csv`; дополнительная редкая конфигурация исследуется как разведочная. Фактическая конфигурация и версии библиотек сохраняются отдельно. Отчёт `report.md` формируется из измеренных результатов; `report.pdf` собирается общим инструментом из корня проекта.

Каждый метод расходует ровно заданное число полных оценок длины; проверки 2-opt включены в бюджет. Конструктивный маршрут ближайшего соседа и граница MST являются отдельными ориентирами, а не участниками сравнения равных бюджетов.

Быстрый проверочный запуск можно направить в отдельный каталог: `experiment.py --runs 2 --budget 2000 --output smoke_results`. При нестандартном `--output` основной `report.md` не изменяется. Для восстановления полного отчёта и результатов используется команда без дополнительных параметров.
