# Лабораторная работа № 2

Вариант 1: рюкзак с ограничениями массы и объёма. Индивидуальные параметры:
N = 11, группа 517, Q = 1, Y = 26. Ключевые операторы ГА и точный DP-эталон
реализованы в `core.py` без готового пакета оптимизации.

## Установка и запуск

Проверено с Python 3.13. Из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe Lab2\main.py
.\.venv\Scripts\python.exe -m pytest Lab2\tests -q
```

При уже установленном окружении достаточно команды запуска. Из директории
`Lab2` можно вызвать `..\.venv\Scripts\python.exe main.py`. Полная серия включает
20 seed для каждого из четырёх методов, по 8000 оценок на запуск. Параметры
задаются в `config.json`; копия фактической конфигурации сохраняется с результатами.

## Файлы

- `data/items.csv`: 40 предметов, фиксированный seed генерации 210026.
- `results/runs.csv`: ценность допустимого архива, фактический бюджет, доля
  допустимых оценок, время, допустимость и score конечного лидера.
- `results/summary.csv`: лучшее, среднее, медиана, выборочное стандартное
  отклонение, худшее, разрыв от точного оптимума.
- `results/convergence.csv`, `results/figures/`: траектории, графики, схема.
- `results/examples.json`: два допустимых и два недопустимых набора.
- `results/best_solution.json`, `results/best_set.csv`: проверенный лучший набор.
- `results/exact_reference.json`, `results/verification.json`: точный эталон и
  машинная проверка всей серии.
- `results/input_data.json`: путь исходной таблицы, SHA-256, число предметов и
  проверенное соответствие генератору из конфигурации.
- `report.md`: краткий академический отчёт по фактически полученным результатам.

Для другого набора seed или бюджета следует скопировать и изменить конфигурацию:

```powershell
.\.venv\Scripts\python.exe Lab2\main.py --config path\config.json --output path\results
```

Альтернативный `--output` сохраняет собственный `report.md` внутри указанного
каталога и не изменяет основной отчёт. Данные можно указать через `--data`;
отсутствующий файл генерируется из конфигурации. Существующая таблица не заменяется.
Отчёт использует фактическое число предметов, пределы ресурсов и коэффициент
штрафа. Для внешней таблицы не приписывается происхождение от заданного seed.

CSV должен иметь колонки `item,mass,volume,value`, уникальные непустые идентификаторы,
положительные целочисленные массы и объёмы, неотрицательные целочисленные ценности.
Суммы целочисленных столбцов должны помещаться в знаковый 64-разрядный тип.
Число предметов в CLI - не менее 30; оно должно совпадать с `objects`. Пределы ресурсов
положительные целые. Вероятности лежат в [0,1], коэффициент штрафа неотрицателен,
seed внутри серии различаются. Бюджет является положительным кратным размера
популяции. Для выполнения задания таблица должна допускать два различных допустимых и два недопустимых
набора; при взаимозависимых ресурсах они могут нарушать оба ограничения одновременно.

Ремонт и случайная выборка используют те же данные и бюджет. Ценность допустимого
решения и штрафной score хранятся раздельно. Время зависит от оборудования и не
является воспроизводимой побитово величиной; seed воспроизводит решения и траектории.
