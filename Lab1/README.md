# Лабораторная работа № 1

Многомерная оптимизация генетическим алгоритмом. Индивидуальный вариант 1: N = 11, группа 517, Q = 1, Y = 26. Функция сферы в шести измерениях, область [-100; 100]⁶.

## Установка и запуск

Из корня проекта (Windows PowerShell):

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe Lab1\run.py
.\.venv\Scripts\python.exe -m pytest Lab1 -q
```

Из директории Lab1 с установленными NumPy и Matplotlib:

```powershell
python run.py --variant 1 --runs 20 --seed-start 1000 --budget 30000
```

Полный запуск выполняет 20 независимых повторений для двух ГА и случайного поиска. Все настройки зафиксированы в config.json. Изменяется только начальный масштаб гауссовской мутации: 0.05 и 0.15. Бюджет каждого метода равен 30 000 оценок функции, включая инициализацию. Эволюционные операторы реализованы в ga.py без готового оптимизатора. Дополнительное задание: BLX-α-кроссовер.

## Состав результатов

- report.md и report.pdf - академический отчёт;
- results/runs.csv - итог каждого запуска, seed, бюджет, время и допустимость;
- results/histories.csv - лучшая найденная оценка на каждом поколении;
- results/summary.csv и summary.json - статистические характеристики;
- results/solutions.json - координаты итоговых решений всех запусков;
- results/experiment.json - фактически использованные настройки и версии;
- results/convergence.png - среднее, минимум и максимум траекторий;
- results/distribution.png - распределения итоговых оценок;
- results/algorithm.png - блок-схема алгоритма.

Для короткой проверки из директории Lab1 допустим `python run.py --runs 2 --budget 1000 --output check_results`; такая серия не заменяет основной эксперимент. При нестандартном каталоге отчёт не перезаписывается. Файл report.pdf формируется общим средством проекта после запуска экспериментов.

Помимо индивидуального варианта модуль objectives.py содержит функции вариантов 1–20 из приложения. Они не используются для расширения выводов основного эксперимента.

Предоставленные результаты, графики и отчёт относятся к варианту 1. Остальные
функции являются вспомогательными реализациями; полный комплект предметных
выводов для иных вариантов не входит в данную работу. Команда `run.py` принимает
только назначенный вариант 1, чтобы вспомогательные функции не выдавались за
проверенный эксперимент с готовым отчётом. Сравниваемые масштабы
мутации должны различаться. Все численные параметры операторов должны быть
конечными; недопустимые настройки отклоняются до начала эксперимента.
Число запусков и бюджет должны быть положительными целыми; seed - неотрицательным
целым, точность успеха - конечной неотрицательной величиной. Параметры N, Q, Y и
учебная группа проверяются на согласованность с назначенным вариантом.
