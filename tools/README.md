# Формирование PDF-отчётов

Из корня проекта после установки общих зависимостей:

```powershell
.\.venv\Scripts\python.exe tools\build_reports.py --render
```

Команда преобразует `Lab*/report.md` в соответствующий `report.pdf` и сохраняет
PNG всех страниц и контактные листы в `tools/_qa/`. Для одного отчёта:

```powershell
.\.venv\Scripts\python.exe tools\build_reports.py Lab1\report.md --render
```

Поддерживаются заголовки, абзацы, списки, таблицы Markdown, изображения PNG с
путями относительно отчёта, блоки кода и математические выражения `$$...$$`.
Блок-схемы перед экспортом должны быть сохранены в PNG. Формулы внутри строки
следует записывать кратко, обычными символами либо в обратных кавычках.

Используются A4, поля 2 см и встроенные шрифты Times New Roman с кириллицей.
По умолчанию шрифты берутся из `C:\Windows\Fonts`; для другой системы следует
передать `--font-dir` с файлами `times.ttf`, `timesbd.ttf`, `timesi.ttf` и
`timesbi.ttf`. Для визуальной проверки нужны PyMuPDF и Pillow.

Каждый PDF содержит SHA-256 своего Markdown-источника в метаданных, чтобы
проверка обнаруживала несинхронный отчёт. После сборки:

```powershell
.\.venv\Scripts\python.exe tools\verify_results.py --output verification.json
```

Проверяются количества запусков и бюджеты, повторяющиеся seed, статистики,
сходимость, допустимость и значения сохранённых решений, точный фронт и
многокритериальные показатели, ресурсы и графические ссылки, текстовые границы
PDF и соответствие контрольной суммы исходнику. Проверка сохранённых файлов
не выполняет оптимизацию заново; полный повтор запускается через `reproduce.py`.
